# Code of conduct

Everyone is welcome to test, use and contribute to TTYloom, including people
making their first contribution.

- Be respectful. Discuss ideas and code without personal attacks.
- Help others learn. Give clear, constructive feedback and allow room for mistakes.
- No harassment, threats, discriminatory abuse or spam.
- Respect privacy. Do not publish someone’s personal information, credentials
  or private messages without their permission.
- Keep issues and pull requests relevant to the project.

These rules apply to the project’s GitHub spaces. Report conduct problems
privately to Christopher AMIAUD at
[christopher.amiaud@gmail.com](mailto:christopher.amiaud@gmail.com). Include only
the context needed to understand the problem. For software vulnerabilities,
follow [SECURITY.md](SECURITY.md).

The maintainer may remove harmful content, close discussions or restrict
participation to address violations, taking severity and repetition into account.
